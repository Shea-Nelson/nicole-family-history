# Nicole’s Family History

A static family-history page covering Nicole’s grandparents: the Anderau line (father’s side) and the Henry, Palfrey, and Trites lines (mother’s side). It includes Revolutionary-era Palfrey surname context.

Plain HTML, CSS, and JavaScript. Published at https://shea-nelson.github.io/nicole-family-history/

Every statement is labeled Confirmed, Likely, Unverified, or Surname context. Living people are named by first name only.
